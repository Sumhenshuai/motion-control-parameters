1. 控制结构总览

        
三环级联矢量控制 (FOC)：位置环 → 速度环 → 电流环，由内到外带宽依次降低。内环在每个 PWM 中断执行一次（周期 \(T_s\)），速度环每 \(N_\omega\) 个中断执行一次，位置环每 \(N_\theta\) 个中断执行一次。

        

          
        

      


      

        
2. PMSM 数学模型 (dq 同步旋转坐标系)

        
采用等幅值 Clarke/Park 变换（dq 电流幅值 = 相电流峰值），\(\omega_e = p\,\omega_m\)。

        
\[ u_d = R_s i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q \]

        
\[ u_q = R_s i_q + L_q\frac{di_q}{dt} + \omega_e\left(L_d i_d + \psi_f\right) \]

        
\[ T_e = \tfrac32\,p\left[\psi_f i_q + (L_d - L_q)\, i_d i_q\right], \qquad J\frac{d\omega_m}{dt} = T_e - T_L - B\omega_m \]

        
SPMSM：\(L_d = L_q\)，磁阻转矩为零，\(K_t = \tfrac32 p\psi_f\)。IPMSM：通常 \(L_q > L_d\)，采用 MTPA 时

        
\[ i_d^{MTPA} = \frac{\psi_f - \sqrt{\psi_f^2 + 8(L_q-L_d)^2 I_s^2}}{4(L_q-L_d)},\qquad i_q = \sqrt{I_s^2 - i_d^2} \]

        
参数换算（本工具使用）：

        
\[ \psi_f = \frac{\sqrt2\,K_{e}}{\sqrt3\,p\cdot \frac{2\pi\cdot 1000}{60}}\quad(K_e:\ \mathrm{V_{rms,LL}/krpm}),\qquad \psi_f = \frac{K_t}{1.5\,p}\quad(K_t:\ \mathrm{N\!\cdot\! m/A_{pk}}) \]

        
机电时间常数 \(\tau_m = \dfrac{J R_s}{1.5\,p^2\psi_f^2}\)，电气时间常数 \(\tau_{d,q} = L_{d,q}/R_s\)。

      


      

        
3. 离散化基础 — 程序里实际运行的是什么

        
数字控制器在采样时刻 \(kT_s\) 采样电流，计算后输出电压，经 PWM 保持一个周期（零阶保持 ZOH）。若本周期计算结果在下一周期才装载到比较寄存器，就有 \(N_d = 1\) 拍计算延时。

        
3.1 对象的 ZOH 等效离散模型

        
\[ G(s) = \frac{1}{Ls+R}\ \xrightarrow{\ \mathrm{ZOH}\ }\ G(z) = \frac{b\,z^{-1}}{1 - a z^{-1}},\qquad a = e^{-RT_s/L},\quad b = \frac{1-a}{R} \]

        
加上 \(N_d\) 拍计算延时：\(G_{tot}(z) = z^{-N_d}\,G(z)\)。等效到连续域，ZOH 贡献约 \(0.5T_s\) 延时，计算延时贡献 \(N_dT_s\)，合计 \(T_d \approx (N_d+0.5)T_s\)（单采单更典型值 \(1.5T_s\)）。

        
3.2 PI 的三种离散化与差分方程

        
连续 PI：\(C(s) = K_p + K_i/s\)。统一写成增量形式 \(u[k] = u[k-1] + b_0 e[k] + b_1 e[k-1]\)，即 \(C(z) = \dfrac{b_0 + b_1 z^{-1}}{1 - z^{-1}}\)：

        

          
方法\(s\) 替换位置式代码\(b_0\)\(b_1\)

          
前向欧拉\(s = \frac{z-1}{T_s}\)u = Kp·e + I; I += Ki·Ts·e;\(K_p\)\(-K_p + K_iT_s\)

          
后向欧拉\(s = \frac{z-1}{zT_s}\)I += Ki·Ts·e; u = Kp·e + I;\(K_p + K_iT_s\)\(-K_p\)

          
双线性\(s = \frac{2}{T_s}\frac{z-1}{z+1}\)I += Ki·Ts/2·(e+e₋₁); u = Kp·e + I;\(K_p + \frac{K_iT_s}{2}\)\(-K_p + \frac{K_iT_s}{2}\)

        

        
TI 等库常用串联形式 \(u = K_p\left(e + K_i'\sum e\right)\)，其中 \(K_i' = T_s/T_i = K_iT_s/K_p\)，工具中一并给出。

        
3.3 离散校核方法

        
频率响应在单位圆上计算：\(L(e^{j\omega T_s})\)，\(0 < \omega < \pi/T_s\)，由此得到相位裕度、幅值裕度和闭环带宽。稳定性看闭环特征方程 \(1 + L(z) = 0\) 的根是否全部满足 \(|z| < 1\)。阶跃响应采用"采样控制器 + 精确离散化的连续对象 + ZOH + 计算延时"仿真，与程序实际运行一致。

        
速度环、位置环是多速率系统：内环以 \(T_s\) 运行，外环以 \(T_\omega\)、\(T_\theta\) 运行。频域校核把内环闭环 \(T_c(e^{j\omega T_s})\) 当作外环对象的一部分，外环部分加入 ZOH \(\frac{1-e^{-j\omega T}}{j\omega T}\)、差分测速平均效应以及离散滤波器；时域仿真则严格按多速率逐拍执行。

      


      

        
4. 电流环

        

          
        

        
4.1 解耦前馈

        
\[ u_d^{ff} = -\omega_e L_q i_q,\qquad u_q^{ff} = \omega_e\left(L_d i_d + \psi_f\right) \]

        
前馈后 d、q 轴均近似为 \(1/(L s + R_s)\) 一阶对象。

        
4.2 连续域零极点对消 (IMC)

        
\[ C(s) = K_p\frac{s + K_i/K_p}{s},\quad \frac{K_i}{K_p} = \frac{R_s}{L}\ \Rightarrow\ C(s)G(s) = \frac{K_p}{Ls} \]

        
\[ K_{pd} = \omega_{cc}L_d,\ \ K_{id} = \omega_{cc}R_s;\qquad K_{pq} = \omega_{cc}L_q,\ \ K_{iq} = \omega_{cc}R_s \]

        
理想闭环为 \(\omega_{cc}/(s+\omega_{cc})\)。考虑延时 \(T_d \approx (N_d + 0.5)T_s\) 后相位裕度近似 \(\mathrm{PM} \approx 90^\circ - \omega_{cc}T_d\cdot\frac{180^\circ}{\pi}\)。PM = 45° 对应 \(f_{cc} = 1/(8T_d)\)，PM = 60° 对应 \(f_{cc} = 1/(12T_d)\)。

        
4.3 z 域直接零极点对消

        
让离散 PI 的零点精确落在对象极点 \(z = a\) 上：\(b_1 = -a\,b_0\)。开环变为

        
\[ L(z) = \frac{K}{z^{N_d}(z-1)},\qquad K = b\,b_0 \]

        
\(N_d = 1\) 时闭环特征方程 \(z^2 - z + K = 0\)：\(K < 1\) 稳定，\(K \le 0.25\) 为实极点（无超调）。工具取 \(K = 1 - e^{-\omega_{cc}T_s}\)，即 \(b_0 = K/b\)，\(b_1 = -a\,b_0\)。小 \(T_s\) 时它与 IMC 结果一致；带宽很高时它更准确，因为对消的是精确的离散极点。

        
4.4 电压限幅与抗饱和

        
SVPWM 线性区 \(\sqrt{u_d^2+u_q^2} \le U_{dc}/\sqrt3\)。增量式 PI 对输出直接限幅即可天然抗积分饱和；位置式需在饱和时停止积分（clamping）或反算 \(I \mathrel{+}= K_{aw}(u_{sat} - u)\)，常取 \(K_{aw} \approx 1/K_p\cdot K_i\)。

      


      

        
5. 速度环

        
把电流闭环近似为 \(1/(1 + s/\omega_{cc})\)，机械对象 \(\frac{K_t}{Js + B}\)，控制器输出 \(i_q^*\)。

        
5.1 带宽法

        
\[ K_{p\omega} = \frac{J\,\omega_{sc}}{K_t},\qquad K_{i\omega} = K_{p\omega}\,\frac{\omega_{sc}}{N} \]

        
忽略 \(B\) 与内环时开环 \(L(s) \approx \frac{\omega_{sc}}{s}\cdot\frac{s + \omega_{sc}/N}{s}\)，穿越频率约为 \(\omega_{sc}\)，PM ≈ \(\arctan N\) 减去内环、测速与采样延时带来的相位滞后。N 越大超调越小，但抗负载扰动恢复越慢。

        
5.2 对称最优

        
\[ T_\Sigma = \frac{1}{\omega_{cc}} + \frac{1}{\omega_f} + T_\omega,\qquad K_{p\omega} = \frac{J}{a K_t T_\Sigma},\qquad T_i = a^2T_\Sigma,\qquad K_{i\omega} = \frac{K_{p\omega}}{T_i} \]

        
穿越频率 \(\omega_c = 1/(aT_\Sigma)\)，相位裕度 \(\mathrm{PM} = \arcsin\frac{a^2-1}{a^2+1}\)。a = 2 时 PM ≈ 37°，a = 2.4 时约 44°，a = 3 时约 53°。

        
5.3 离散实现要点

        
差分测速 \(\omega[k] = (\theta[k] - \theta[k-1])/T_\omega\) 等效平均滤波（约 \(T_\omega/2\) 延时），一阶 IIR 滤波 \(y \mathrel{+}= \alpha(x - y)\)，\(\alpha = 1 - e^{-\omega_f T_\omega}\)。PI 离散用 \(K_{i\omega}T_\omega\)。输出 \(i_q^*\) 限幅于 \(I_{max}\)，并做积分抗饱和。

      


      

        
6. 位置环

        
\[ \omega^* = K_{pp}(\theta^* - \theta) + K_{vff}\,\dot\theta^*,\qquad i_q^{ff} = K_{aff}\,\ddot\theta^*,\quad K_{aff} = \frac{J}{K_t} \]

        
速度环视为 1 时，位置闭环 \(\frac{K_{pp}}{s + K_{pp}}\)，因此 \(K_{pp} = \omega_{pc} = 2\pi f_{pc}\)（单位 1/s）。匀速运动时跟随误差 \(e_\theta = (1-K_{vff})\,\omega/K_{pp}\)。一般取 \(f_{pc} \le f_{sc}/4\)，加速度前馈可显著减小加减速时的跟随误差。

      


      

        
7. 观测器

        
7.1 锁相环 PLL（角度/速度提取）

        
\[ \varepsilon = \sin(\theta - \hat\theta)\approx \theta - \hat\theta,\quad \hat\omega = \left(K_p + \frac{K_i}{s}\right)\varepsilon,\quad \hat\theta = \frac{\hat\omega}{s} \]

        
\[ \frac{\hat\theta}{\theta} = \frac{K_ps + K_i}{s^2 + K_ps + K_i}\ \Rightarrow\ K_p = 2\zeta\omega_n,\quad K_i = \omega_n^2 \]

        
若误差取未归一化的 \(\varepsilon = -\hat e_\alpha\cos\hat\theta - \hat e_\beta\sin\hat\theta\)，其幅值为 \(|E| = \omega_e\psi_f\)，增益需除以 \(|E|\)（或先对 \(\hat e\) 归一化）。离散：\(\hat\theta[k+1] = \hat\theta[k] + T_s\hat\omega[k]\)。

        
7.2 PI 型反电势观测器 (扩展反电势, αβ 系)

        
采用 \(L_q\) 模型：\(L_q\frac{di}{dt} = u - R_s i - e\)，IPMSM 的扩展反电势 \(e = [(L_d-L_q)(\omega_e i_d - \dot i_q) + \omega_e\psi_f]\,[-\sin\theta,\ \cos\theta]^T\)。

        
\[ L_q\frac{d\hat i}{dt} = u - R_s\hat i - \hat e,\qquad \hat e = \left(K_{po} + \frac{K_{io}}{s}\right)(\hat i - i) \]

        
\[ \frac{\hat e}{e} = \frac{K_{po}s + K_{io}}{L_qs^2 + (R_s + K_{po})s + K_{io}}\ \Rightarrow\ K_{po} = 2\zeta\omega_oL_q - R_s,\quad K_{io} = \omega_o^2L_q \]

        
αβ 系中反电势是频率为 \(\omega_e\) 的正弦量，观测器会带来幅值和相位误差，工具给出额定转速下的相位滞后，可在角度上补偿。建议 \(f_o \ge 3\sim5\,f_{e,max}\)。

        
7.3 滑模观测器 SMO

        
\[ L\frac{d\hat i}{dt} = u - R_s\hat i - z,\quad z = k\,\mathrm{sat}\!\left(\frac{\hat i - i}{\Phi}\right),\quad \hat e = \frac{\omega_c}{s + \omega_c}z \]

        
滑模存在条件 \(k > |e|_{max}\)，取 \(k = \eta\,\omega_{e,max}\psi_f\)。低通滤波带来相位滞后 \(\Delta\theta = \arctan(\omega_e/\omega_c)\)，需在角度上补偿；离散实现时电流抖振幅值约 \(kT_s/L\)。

        
7.4 负载转矩观测器 (Luenberger)

        
\[ \dot{\hat\omega} = \frac{K_ti_q - \hat T_L - B\hat\omega}{J} + l_1(\omega - \hat\omega),\qquad \dot{\hat T}_L = -l_2(\omega - \hat\omega) \]

        
\[ s^2 + \left(\frac{B}{J} + l_1\right)s + \frac{l_2}{J} = s^2 + 2\zeta\omega_os + \omega_o^2\ \Rightarrow\ l_1 = 2\zeta\omega_o - \frac{B}{J},\quad l_2 = J\omega_o^2 \]

        
补偿电流 \(i_q^{comp} = \hat T_L/K_t\) 加到速度环输出。观测器在速度环周期 \(T_\omega\) 执行，离散极点为 \(\mathbf{I} + T_\omega\mathbf{A}\) 的特征值。

      


      

        
8. 标幺化 (定点/Q 格式程序常用)

        
\[ K_{p,pu}^{cur} = K_p\frac{I_b}{U_b},\quad K_{i,pu}^{cur} = K_i\frac{I_b}{U_b};\qquad K_{p,pu}^{spd} = K_{p\omega}\frac{\omega_{mb}}{I_b},\quad K_{i,pu}^{spd} = K_{i\omega}\frac{\omega_{mb}}{I_b} \]

        
\[ K_{pp,pu} = K_{pp}\,\frac{2\pi}{\omega_{mb}}\quad(\theta_{pu} = 1\ \text{对应一圈}),\qquad \omega_{mb} = \frac{2\pi n_b}{60} \]

      


      

        
9. 调试建议

        

          
环路常用范围说明

          
电流环\(f_{cc} \le f_s/10\)，PM ≥ 45°先锁轴做 d 轴阶跃，检查超调。超调大说明延时被低估或电感偏小。

          
速度环\(f_{sc} \approx f_{cc}/5 \sim f_{cc}/10\)惯量比大时先辨识 J。噪声大时降低滤波截止或带宽。

          
位置环\(f_{pc} \approx f_{sc}/3 \sim f_{sc}/5\)不允许超调的场合 \(f_{pc}\) 取更低值，并配合前馈。

          
观测器PLL \(f_n\) 高于速度环带宽，EMF 观测器 \(f_o \ge 3 f_{e,max}\)带宽越高噪声越大。注意离散极点 \(|z| < 1\)，且实际值越小越好。

        

        
参数辨识误差的影响：电感偏差主要影响电流环增益（带宽按比例变化），电阻偏差只影响 PI 零点（低频）。惯量偏差直接按比例改变速度环带宽。
