# motion-control-parameters

PMSM（永磁同步电机）控制参数整定工具：输入电机参数与控制器采样设置，按带宽自动计算电流环、速度环、位置环和观测器参数，并在离散域 (z 域) 校核。

## 使用

用浏览器直接打开 `pmsm-tuner.html` 即可，无需安装。帮助页的公式由 MathJax CDN 渲染，离线时显示 TeX 源码，其余功能可完全离线使用。

## 功能

- **电机**：SPMSM / IPMSM，Rs、Ld、Lq、ψf（也可输入 Ke 或 Kt 自动换算）、极对数、惯量、摩擦、额定/极限值。
- **控制器**：开关频率、单采单更/双采双更、计算延时拍数、PI 离散化方法（前向欧拉/后向欧拉/Tustin）、速度环与位置环分频、测速滤波、编码器分辨率。
- **电流环**：连续域 IMC 零极点对消，或 z 域直接零极点对消；ZOH 离散对象 + 计算延时下的离散 Bode、相位/幅值裕度、z 平面闭环极点、采样阶跃仿真。
- **速度环**：带宽法或对称最优；多速率离散校核（内环 Ts、外环 Tω、差分测速、IIR 滤波），速度阶跃 + 负载扰动仿真。
- **位置环**：P + 速度/加速度前馈，跟随误差，阶跃仿真。
- **观测器**：PLL、PI 型扩展反电势观测器、滑模观测器、负载转矩观测器，前向欧拉离散极点校核。
- **输出**：Kp、Ki、Ki·Ts、串联式 Ki'、增量式 b0/b1、标幺值；可导出 C 头文件、MATLAB/Simulink 脚本、JSON。
